# Blocks that make a signal of their own (CAL-128), in the flat world's chunk (0, 0) by its spawn,
# on a stone floor, as the receivers fixture lays one. Pressing a button or a plate, or a minecart
# on a detector rail, comes with players and entities, so each source is set as a command sets it,
# pressed or not, beside a lamp that shows its signal. An observer clock's pulses go into glass by
# the lamp, which doesn't carry them, so the lamp is only told of a change every pulse and reads
# the source alone: lit while it's powered, going out once it isn't. A lightning rod set struck has
# its tick to let go waiting in the save, and so does a tripwire hook whose line was tripped as a
# wire was broken.
setworldspawn 0 -60 0
fill 0 -61 0 15 -61 15 minecraft:stone

# The first column: each clock at x 1 and 2, its glass at x 3, the lamp at x 4, by a stone at x 5

# lectern turning a page; a detector rail set pressed, which nothing presses, so it's let go as
